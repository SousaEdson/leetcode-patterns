# 113. Path Sum II
https://leetcode.com/problems/path-sum-ii

Travessia pre order, sem muitos detalhes adicionais com exceção do targetSum ser decrementado em cada nó para não precisar de uma variável adicional para registrar a soma atual. Complexidade quadrática no pior caso onde a árvore esteja quase linear, como o exemplo abaixo:
```
       1
      /
     2 
    / \
   3   5
  /  \ 
 4    6
```
A quantidade de folhas vai ser aproximadamente metade da quantidade de nós. 
```Java
class Solution {
    private void findPaths(TreeNode root, Deque<Integer> path, List<List<Integer>> paths, int targetSum){        
        if(root == null) return;
        path.add(root.val);
        targetSum -= root.val;

        if(root.left == null && root.right == null){
            if(targetSum == 0) paths.add(new ArrayList<>(path));
        }else{
            findPaths(root.left, path, paths, targetSum);
            findPaths(root.right, path, paths, targetSum);
        }

        path.removeLast();
    }

    public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
        List<List<Integer>> paths = new ArrayList<>();
        findPaths(root, new ArrayDeque<>(), paths, targetSum);
        return paths;
    }
}
```
