# 222. Count Complete Tree Nodes
https://leetcode.com/problems/count-complete-tree-nodes

O problema pede para contabilizar a quantidade de nós de uma árvore binária completa, ou seja, todos os níveis estão completamente cheios com exceção possívelmente do último, onde os nós estão dispostos da esquerda para a direita.
Para resolver esse problema com uma complexidade de tempo menor do que $O(n)$ é necessário evitar de contabilizar nó por nó. Isso é feito eliminando subárvores que podem ter sua altura calculada de forma mais rápida. Para cada nó é feito o seguinte:
- Contabiliza a distância da raiz até a folha mais a esquerda da subárvore da esquerda
- Contabiliza a distância da raiz até a folha mais a esquerda da subárvore da direita
- Caso a subárvore da direita tenha uma profundidade maior, isso indica que os nós do último nível estão contidos somente na esquerda. Logo, a quantidade de nós na direita pode ser contabilizada de forma rápida utilizando a fórmula $2^{n + 1} - 1$. 
- Caso contrário, os nós do último nível estão na subárvore da direta e a mesma fórumla é utilizada para se obter a quantidade de nós da esquerda.
- Por fim, resta contabilizar a quantidade de nós da subárvore que não foi possível utilizar a fórmula. Para isso, basta utilizar recursão para aplicar o mesmo processo nessa subárvore. A função de recursão é basicamente o seguinte:
```Java
if(leftDepth > rightDepth){
    return 1 + countNodes(root.left) + (int) Math.pow(2, rightDepth + 1) - 1;
}else{
    return 1 + countNodes(root.right) + (int) Math.pow(2, leftDepth + 1) - 1;
}
```
O 1 que é adicionado é a contabilização do nó atual.
No pior caso o processo é executado da raiz até a folha e cada execução realiza duas travessias da raiz até a folha das subárvores. Ambas as operações possuem complexidade $O(logn)$, logo a complexidade final é de $O(logn)^2$, que é menor do que $O(n)$.
```Java
class Solution {
    public int countNodes(TreeNode root) {
        if(root == null) return 0;
        int leftDepth = getLeftTreeDepth(root.left);
        int rightDepth = getLeftTreeDepth(root.right);

        if(leftDepth > rightDepth){
            return 1 + countNodes(root.left) + (int) Math.pow(2, rightDepth + 1) - 1;
        }else{
            return 1 + countNodes(root.right) + (int) Math.pow(2, leftDepth + 1) - 1;
        }
        
        
    }
    private int getLeftTreeDepth(TreeNode root){
        int depth = -1;
        while(root != null) {
            root = root.left;
            depth++;
        }
        return depth;
    }
}
```
