# 108. Convert Sorted Array to Binary Search Tree
https://leetcode.com/problems/convert-sorted-array-to-binary-search-tree

Como o array está ordenado, o meio pode ser definido como a raiz, que dessa forma haverá uma quantidade quase igual (com no máximo um nó de diferença para arrays com uma quantidade par de nós) em cada um dos lados. Basta aplicar a mesma lógica para o sub-array da direta e dá esquerda, de forma recursiva. Esse divide and conqueer garante que a árvore final estará balanceada.
Por fim, a árvore é construída de forma preorder: root - left - right;
```Java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {

    private TreeNode buildBST(int[] nums, int l, int r){
        if(r < l) return null;
        int mid = (l + r) / 2;
        return new TreeNode(nums[mid], buildBST(nums, l, mid - 1), buildBST(nums, mid + 1, r));
    }

    public TreeNode sortedArrayToBST(int[] nums) {
        return buildBST(nums, 0, nums.length-1); 
    }
}
```
