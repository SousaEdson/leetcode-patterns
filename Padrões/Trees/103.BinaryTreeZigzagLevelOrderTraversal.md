# 103. Binary Tree Zigzag Level Order Traversal
https://leetcode.com/problems/binary-tree-zigzag-level-order-traversal

BFS processando todos os nós de um nível por vez. A cada nível, todos os nós são salvos em uma lista e é utilizada uma toggle flag para decidir se os elementos vão ser utilizados da esquerda para a direita ou da direita para a esquerda, gerando assim o zig zag.
Utilizar ``nodes = nodes.reversed();`` a partir do Java 21 é mais eficiente, a lista não é revertida de fato.
```Java
class Solution {
    public List<List<Integer>> zigzagLevelOrder(TreeNode root) {
        
        List<List<Integer>> zigzagOrderedNodes = new ArrayDeque<>();
        Queue<TreeNode> nodeQueue = new LinkedList<>();
        boolean isLeftToRight = true;

        if(root == null) return zigzagOrderedNodes;
        nodeQueue.offer(root);

        while(!nodeQueue.isEmpty()){
            int width = nodeQueue.size();
            List<Integer> nodes = new ArrayList<>();
            for(int i=0; i<width; i++){
                TreeNode currentNode = nodeQueue.poll();
                nodes.add(currentNode.val);
                if(currentNode.left != null) nodeQueue.offer(currentNode.left); 
                if(currentNode.right != null) nodeQueue.offer(currentNode.right);                                 
            }
            if(!isLeftToRight) nodes = nodes.reversed();
            zigzagOrderedNodes.add(nodes);
            isLeftToRight = !isLeftToRight;
        }

        return zigzagOrderedNodes;       
    }
}
```
